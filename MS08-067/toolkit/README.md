# Toolkit

The original author of `idl_parser.py` and `idl_scraper.py`: [rpc_toolkit by akamai](https://github.com/akamai/akamai-security-research/tree/main/rpc_toolkit)

The toolkit might not be compatible with the latest native Python library. In addition, I think the original features are insufficient. Therefore, I modified the toolkit.

# Usage

```bash
python3 idl_scraper.py
python3 idl_parser.py IDLFiles/ rpc_database.csv -r
python3 find.py
```
